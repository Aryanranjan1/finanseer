# **App Name**: SnabbX Landing

## Core Features:

- Dynamic Hero Animation: Implement a Rive-based hero animation that visualizes data flows and abstract charts.
- Interactive UI Elements: Create interactive buttons and icons with subtle Rive animations on hover and click.
- Account Comparison Tool: Side-by-side comparison of account types, styled with clear cards and bold CTAs.
- Client Trust Carousel: Display Trustpilot reviews and client testimonials in a visually appealing carousel.
- Personalized Tagline Tool: Based on user activity or context, suggest a tagline for SnabbX's hero section.
- Authentication Integration: Firebase integration for user authentication and secure data handling.
- Adaptive Pop-up: Develop a smooth entrance animation using Rive and integrate it with firebase for any small loaders or success state pop-ups

## Style Guidelines:

- Primary color: Muted navy blue (#24344D) for a professional, tech-oriented feel.
- Background color: Light gray (#F0F4F8) to ensure readability and a clean aesthetic.
- Accent color: Vibrant electric blue (#7DF9FF) for CTAs and interactive elements to draw user attention.
- Headline font: 'Satoshi' (sans-serif) for a unique and strong display, giving a premium look.
- Body font: 'Inter' (sans-serif) for highly legible and clean paragraph text.
- Use high-quality, tech-inspired icons with subtle Rive animations for interactive elements.
- Strict adherence to the 8px grid system for all spacing, padding, and element dimensions to ensure a clean and consistent layout.
- Micro-animations: Delicate and fast animations on interactive elements, loaders and pop ups, created with Rive.
